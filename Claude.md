# Skillpath Technical Assessment

## Project goal

This project is a junior developer technical assessment for a Framer landing page called Skillpath.

The assignment PDF in this repository is the source of truth for the requirements.

## Development principles

- I am the primary developer and decision maker.
- Claude Code: engineering assistant.
- Do not implement large features without first explaining the approach.
- Prefer simple, readable, junior-level React code.
- Avoid unnecessary abstractions and dependencies.
- Do not hide important logic behind libraries unless there is a clear reason.
- I need to understand and be able to explain every line of submitted code.
- When a design decision has tradeoffs, explain them before implementation.
- When something could fail, explicitly identify the failure mode.
- After significant changes, explain what changed and why.
- Test edge cases rather than assuming the happy path works.

## Assignment priorities

Correctness and reliability come before visual polish.

Pay particular attention to:
- API failures
- loading state
- error state
- empty state
- country API failure while course API succeeds
- currency conversion
- responsive grid
- Framer property controls
- variable course counts

## AI usage

Be transparent about AI-assisted development.

Do not conceal AI-generated code.

When AI-generated code is used, explain it and help me understand it before treating it as final.
